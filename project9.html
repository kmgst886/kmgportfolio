Project: Treasure Pleasure

Type: Physical Arcade Machine / Interactive Game

Description: This project documents the creation of a physical arcade machine from concept sketches to a fully built, playable game.

Overview

The arcade machine blends interactive design and physical construction into one cohesive experience.

Project Summary

Includes concept art, sketching, panel design, wiring, woodworking, gameplay development, and exhibit setup.

Original Game Idea

The early idea featured a simple treasure-hunting reflex game with neon visuals.

Concept Sketches

Sketches explored cabinet shape, button layout, and theme direction.

Field Trips

Arcade visits helped refine ergonomics and user interaction details.

Project Proposal

Outlined goals, materials, timeline, and visual direction.

Sketching Side Panels

Side panel artwork was built from neon-heavy sketches.

Beginning Construction

Initial wood cutting and structural assembly began the cabinet build.

Starting to Assemble

Panels, supports, screen placement, and joinery were aligned.

Piecing It Together

Hardware mounts and wiring channels were integrated.

Carpet Design

A custom neon-pattern arcade carpet complemented the cabinet.

Painting the Machine

Neon gradients and glowing outlines created a blacklight-reactive finish.

Adding In Controls

Joystick and button integration with wiring harnesses completed input assembly.

Making the Game

Game mechanics, scoring, and animation were prototyped for cabinet play.

Game Idea Pivot

Based on testing, mechanics were improved for fast-paced, rewarding play.

Final Game Design

Final gameplay featured polished art, sound, and responsive controls.

Final Machine

The completed arcade machine stood fully functional with glowing neon panels.

Exhibition Setup: Black Lights & Stool

Displayed under UV light with a themed stool for full immersion.

Reflection

A deep exploration of woodworking, electronics, painting, and game development.
