Project: Mobile Version of Shipping Craze

Type: Mobile Game Concept

Description: A mobile adaptation of the board game Shipping Craze. Redesigned UI and mechanics to fit mobile screens while keeping the strategic gameplay intact.

Gameplay Screenshots

Creative Process

Started with wireframes, then iterated designs in Figma. Implemented touch-friendly interactions and simplified rules for mobile users. Conducted playtesting to refine user experience.

Next Steps

Planning to develop a full playable mobile prototype and eventually release it on app stores.

Struggles with Mobile Development & Controller Pairing

One of the most difficult challenges in creating the mobile version of Shipping Craze was getting the game to work properly with external controllers. The game worked flawlessly when using a trackpad — movement was smooth, interactions were accurate, and gameplay behaved exactly as coded.

But the moment a controller was connected, everything went chaotic. Instead of responding to inputs normally, the game started triggering random interactions, skipping actions, or performing entirely different events than intended. Buttons that were supposed to open menus ended up triggering actions, and movement controls would conflict with gameplay logic.

After doing extensive research, testing individual mappings, and isolating event triggers, I discovered the real problem: many of my conditions and events were unintentionally canceling each other out.

Because controller input introduces simultaneous directional and button signals, multiple conditions became true at the same time — causing the game engine to fire overlapping events. This created a chain reaction of incorrect behaviors.

Once I reorganized the event logic and restructured the conditions to avoid conflicts, the game finally started responding correctly. This process taught me a lot about:

  • input prioritization
  • event conflict resolution
  • how mobile and controller inputs differ in execution
  • the importance of isolating and testing logic pathways

It was a frustrating but valuable learning experience in debugging and understanding how real-time input systems interact with game logic.
